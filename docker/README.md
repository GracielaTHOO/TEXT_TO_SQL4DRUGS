# 💊 Text-to-SQL médicaments : image de la démo

Image Docker autonome : Ollama, le modèle `qwen2.5-coder:1.5b`, la base BDPM et la démo Gradio.
Questions en français sur la Base de données publique des médicaments (ANSM), traduites en SQL et
exécutées en lecture seule.

- Code, méthodologie et résultats : https://github.com/GracielaTHOO/TEXT_TO_SQL4DRUGS
- Données : BDPM, ANSM, licence ouverte (mise à jour mensuelle)
