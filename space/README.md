# 💊 Text-to-SQL médicaments

Posez une question en français sur la **Base de données publique des médicaments** (ANSM) :
un LLM local servi par Ollama la traduit en SQL, exécuté en lecture seule sur une base SQLite.

- Code, méthodologie et résultats d'évaluation : https://github.com/GracielaTHOO/TEXT_TO_SQL4DRUGS
- Données : BDPM, ANSM, licence ouverte (mise à jour mensuelle)

> Démonstration technique. Ne constitue pas un avis médical.
